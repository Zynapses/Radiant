# OMEGA Documentation Policy

> ⚠️ **THIS POLICY IS MANDATORY AND HAS NO EXCEPTIONS** ⚠️

## The Rule

**ALL OMEGA-related documentation MUST be written to `docs/09-OMEGA-GENESIS.md`.**

As of 2026-02-10, doc 19 was merged INTO doc 09. There is now ONE authoritative OMEGA document.

This includes but is not limited to:

- OMEGA Protocol changes
- Quantum Brain / Quantum State Engine changes
- Helix Safety Kernel changes
- Firmware hot-swap or firmware enforcer changes
- Cartridge boot sequence changes
- Ambition chemical system changes
- Soft ROM changes
- Model router / drift governance changes (when OMEGA-specific)
- Global Brain / federated learning changes
- Genesis Forge changes
- Genesis Lab changes
- Resonant Index changes
- LIVS-M changes
- Any new OMEGA subsystem or feature

- ❌ Splitting OMEGA content across multiple documents
- ❌ Documenting OMEGA features in brain docs (07) instead of here
- ❌ Skipping this document for "minor" OMEGA changes
- ❌ Writing to the archived `docs/19-OMEGA-QUANTUM-MODEL-AI.md` (it no longer exists in docs/)
